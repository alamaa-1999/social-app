**Provenance**: unlike Vollkorn's own upright/italic files (see `../vollkorn/README.md`), Google
Fonts distributes Vollkorn SC as real static per-weight files, not a variable font - no
instancing needed. `VollkornSC-Regular.ttf` here is exactly the upstream file
(`google/fonts` repo, `ofl/vollkornsc/VollkornSC-Regular.ttf`), unmodified. Used for the
article byline's publish-date text (article/date, Figma node 362:5435) - a genuine small-caps
letterform design, not synthetic small-caps via a CSS/style property on the regular cut.
